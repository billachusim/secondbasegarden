# Garden Menu Connect

I want to build a menu landing page for a garden lounge in Asaba, Nigeria. First check google maps business for 2nd Base Garden Asaba, gather what you can, then let's disuss how we will build a qr code that customers can scan when seated on table and it takes them to a landing page with the list and prices of foods and drinks and services with pictures, sorted via categories. the landing page will also have other necessary info
